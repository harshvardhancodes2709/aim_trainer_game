# Aim Trainer 🎯

A simple Aim Trainer game built using Python and Pygame. The game challenges players to improve their mouse accuracy and reaction speed by clicking targets as quickly as possible before they disappear.

## Features

- Targets appear at random positions on the screen.
- Targets grow and shrink over time.
- Three lives available per game.
- Tracks the total number of successful hits.
- Counts missed targets and remaining lives.
- Displays elapsed time and hitting speed.
- Calculates final accuracy percentage.
- Shows a game-over screen with performance statistics.

## How to Play

1. Run the Python program.
2. Targets will start appearing at random positions.
3. Click on the targets before they disappear.
4. Avoid missing too many targets.
5. The game ends when you lose all three lives.
6. Review your final performance statistics.

## Game Statistics

The game tracks the following statistics:

| Statistic | Description |
|---|---|
| Time | Total time spent playing |
| Speed | Successful hits per second |
| Hits | Total targets successfully clicked |
| Lives | Remaining lives |
| Accuracy | Percentage of successful clicks |

   ```bash

   ```

   ```bash

   ```

Run the following command:

```bash

```

The game window will open automatically. Use your mouse to click the targets.
